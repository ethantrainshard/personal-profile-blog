NetSentinel is a real-time network intrusion detection system that uses machine learning to identify anomalous network traffic patterns. Unlike signature-based IDS solutions, NetSentinel can detect previously unknown attack vectors by learning what normal traffic looks like for each network segment.

The system processes network flow data (NetFlow, sFlow) in real-time, extracting features such as packet sizes, inter-arrival times, protocol distributions, and connection patterns. A lightweight anomaly detection model flags deviations for further analysis.
